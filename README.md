# Estudio de animación

Producción de cortos animados con Remotion + React + TypeScript, operada con Claude Code.
Instrucciones permanentes: [`CLAUDE.md`](./CLAUDE.md).

```
animaciones/
├── CLAUDE.md          instrucciones del estudio
├── engine/            componentes de animación (cámara, escena, subtítulos, audio)
├── styles/            biblioteca de estilos  → GRAPHITE_HORROR_01 (v1.0)
├── assets/            recursos compartidos (audio provisional…)
├── projects/          un proyecto Remotion por video (+ _template/)
├── outputs/           videos, pruebas de estilo y storyboards
└── references/        referencias y documentación
```

Empezar un video nuevo: ver [`projects/_template/README.md`](./projects/_template/README.md).
